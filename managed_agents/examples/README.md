# Example IC Memos

Place example Investment Committee (IC) PowerPoint memos in this directory.
The managed agent mounts these at `/mnt/examples/` so it can study Subtext's
house style — slide ordering, table formatting, chart conventions, and data
presentation patterns.

## What to include

- 2–3 representative IC memo decks (.pptx) that show the standard format
- Ideally covering different deal types (multifamily, student housing, mixed-use)
- These should be finalized/approved memos, not drafts

## How they're used

The agent reads these files at the start of each run to understand:
- Expected slide order and section structure
- Table formatting conventions (headers, units, number formats)
- Chart types and color schemes
- Narrative tone and length
- Footer and branding conventions

## Important

- Do NOT commit actual IC memos to the repository (they contain confidential deal data)
- Add `.pptx` files here manually on the deployment machine
- This directory is `.gitignore`'d to prevent accidental commits
