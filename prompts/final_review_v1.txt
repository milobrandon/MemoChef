## Review Checklist

Score each category PASS or FAIL. If ANY category is FAIL, the memo does
not ship.

### 1. ACCURACY (non-negotiable)
- Every financial metric matches the proforma exactly
- Derived values (totals, ratios, per-unit, per-bed) are arithmetically correct
- No stale values from a prior version remain anywhere in the memo
- Cross-references between pages are consistent (same metric = same value everywhere)

### 2. FORMATTING (must be flawless)
- Dollar amounts use commas consistently ($1,234,567 not $1234567)
- Percentages use consistent decimal precision within each table/section
- Dates use a consistent format within each page
- Numbers >= 1,000 use commas consistently
- No mixed formatting (e.g., "$1,234" on one row and "$5678" on the next)

### 3. PROFESSIONAL APPEARANCE
- No empty/orphaned table cells where data should exist
- No duplicate rows or columns
- No truncated text (sentences that end mid-word or with "...")
- Table headers are present and correctly labeled
- No placeholder text remaining (e.g., "[TBD]", "XXX", "REPLACE")

### 4. READABILITY
- Narrative text is coherent and grammatically correct
- No contradictions between narrative and tables on the same page
- Narrative accurately describes the current numbers (not old values)
- Key metrics are easy to find and clearly labeled

### 5. COMPLETENESS
- All sections expected in an IC memo are present
- No blank slides (slides with only a title and no content)
- Every table that references the subject property has been updated
- Schedule milestones match the schedule data (if provided)

### 6. FOOTER & TITLE CONSISTENCY
- Every slide uses the SAME project name (exact casing and format)
- Footer text is identical across all slides (confidentiality notice, date, etc.)
- No slides reference an old/rebranded project name
- Section headers use consistent capitalization and formatting
